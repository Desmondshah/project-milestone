References and Learning Resources

Official sources used in this project

These references were chosen because they come from web standards groups or primary documentation sources. Accessed on March 24, 2026.

  • Accessibility

    W3C Web Accessibility Initiative: Introduction to Web Accessibility

    Explains what web accessibility means, why it matters, and how accessible design supports people with disabilities as well as broader usability.

    https://www.w3.org/WAI/fundamentals/accessibility-intro/

  • Accessibility

    MDN Web Docs: Accessibility

    Provides a developer-focused overview of accessibility concepts and related guides for practical implementation.

    https://developer.mozilla.org/docs/Web/Accessibility

  • Responsive Design

    MDN Learn Web Development: Responsive Web Design

    Describes flexible grids, breakpoints, and layout strategies for adapting content to different screens.

    https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/CSS_layout/Responsive_Design

  • Responsive Design

    web.dev: Responsive Web Design Basics

    Summarizes viewport setup, flexible images, layout methods, and modern responsive design patterns.

    https://web.dev/responsive-web-design-basics/

  • Performance

    web.dev: Web Vitals

    Defines the Core Web Vitals metrics and explains what counts as a good experience for LCP, INP, and CLS.

    https://web.dev/articles/vitals

  • Performance

    web.dev: Why Does Speed Matter?

    Connects site speed to user retention, conversions, and user experience outcomes.

    https://web.dev/learn/performance/why-speed-matters

  • Forms and Validation

    MDN Web Docs: Your First Form

    Reviews labels, controls, and structure for building HTML forms that users can understand and complete.

    https://developer.mozilla.org/en-US/docs/Learn_web_development/Extensions/Forms/Your_first_form

  • Forms and Validation

    MDN Web Docs: Client-side Form Validation

    Explains how built-in browser validation and JavaScript can work together to give immediate feedback.

    https://developer.mozilla.org/en-US/docs/Learn_web_development/Extensions/Forms/Form_validation

  • Accessibility

    W3C WAI Tutorials: Forms Concepts

    Describes accessible labeling, grouping, instructions, and error handling for forms and interactive tasks.

    https://www.w3.org/WAI/tutorials/forms/
