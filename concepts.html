Glossary Page

Key concepts for this research topic

These concepts connect the technical side of web development with the user experience side. Together they explain how a website can be well structured, adaptable, and usable for more people.

Semantic HTML
Using elements for their real meaning, such as headings, lists, articles, buttons, and navigation, so browsers and assistive technologies understand the structure of the page.
Accessibility
Designing and developing websites so people with disabilities can perceive, understand, navigate, and interact with the content effectively.
Responsive Design
A design approach that allows content and layout to adapt to different screen sizes, device capabilities, and orientations without creating separate websites for each device.
CSS Grid and Flexbox
Modern CSS layout systems that make it easier to create flexible rows, columns, and content areas that respond to available space.
Core Web Vitals
A set of user-centered performance metrics that focus on loading speed, responsiveness, and visual stability in real-world page usage.
Progressive Enhancement
Building the basic content and functionality first, then enhancing the experience for more capable browsers or devices without breaking the core experience.

How the Concepts Connect

Semantic HTML supports accessibility. Responsive design helps that content stay usable on different screens. Performance work helps the experience remain fast and stable. Progressive enhancement connects these ideas by encouraging developers to start with a strong baseline and improve from there.
