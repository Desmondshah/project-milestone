About Me and the Project

Student profile and project overview

My name is Desmond Shah, and I am an IT student. I made this website for IT 3203 to share research on modern web development. The main focus is how accessibility, responsive design, and performance work together to make websites better, and milestone 2 adds a quiz to make the project more interactive.

This page is a quick intro to me and to how the project changed from milestone 1 to milestone 2.

Mini Resume Snapshot

  • Name: Desmond Shah
  • Role: IT student with an interest in web development
  • Course: IT 3203 Web Development
  • Current Skills: HTML, CSS, page layout, JavaScript fundamentals, research, and frontend problem solving
  • Goal: Build websites that are clear, accessible, responsive, visually organized, and easy to maintain

Why this topic

I chose web development as a research topic because it combines technical standards, design decisions, and user experience in one field.

What this site demonstrates

The project shows semantic HTML, responsive layout techniques, shared navigation, image use, tables, lists, a reusable stylesheet, and JavaScript quiz scoring.

Milestone 2 work

In this milestone, I added more research content, more references and glossary terms, improved the navigation, and built a self-assessment quiz with instant feedback and reset behavior.

Implementation Notes

The site uses a shared layout and style system so new pages still match the rest of the project. The quiz page uses accessible form controls, grouped questions, and a JavaScript results panel that shows the total score, pass or fail status, and the correct answer for each question.
